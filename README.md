# 2025-IEEE-Network-ChirpDelayDopplerModulationISAC
Simulation codes for our paper, titled *Chirp Delay-Doppler Domain Modulation: A New Paradigm of Integrated Sensing and Communication for Autonomous Vehicles*, which has been accepted by **IEEE Network** and is available on [arXiv](https://arxiv.org/abs/2505.16807).

The simulation codes were developed and tested in the "Matlab 2024A" environment.
